Filter Data Flow
1
User selects a filter

FilterBar.vue updates the useFilters composable — a module-level singleton, so state is shared across all views without Pinia or Vuex.

2
View watches filter state

Each view uses watch() on the composable's refs. Any filter change triggers a fresh API call automatically.

3
Filters converted to API params

getCurrentFilters() maps UI state to query params: selectedLocation → warehouse, selectedPeriod → month, etc.

4
HTTP request via api.js

Axios sends GET /api/orders?warehouse=Tokyo&category=sensors&month=Q1-2025. All 13 methods live here — single place for base URL and param construction.

5
Backend filters in-memory

apply_filters() skips params set to 'all'. filter_by_month() supports both direct months (2025-01) and quarters (Q1-2025).

6
Pydantic validates & returns

Response is validated against a typed model (e.g. List[Order]) before serialization — prevents malformed data reaching the frontend.

7
Vue updates computed properties

Raw data lands in a ref(). Downstream computed() properties for aggregations, charts, and KPIs re-evaluate automatically — no manual refresh needed.

Frontend Structure
Views (Pages)
Dashboard — KPI cards, donut charts, top products, inventory shortages
Inventory — Searchable table, reorder status badges, detail modal
Orders — Status summaries, expandable line items, date range filtering
Spending — Revenue vs costs, category breakdown, transactions list
Demand — Forecasted vs current demand, trend indicators
Reports — Quarterly stats, monthly trend analysis
Composables (Shared Logic)
useFilters — Global singleton: period, location, category, status refs. getCurrentFilters() converts to API format.
useAuth — Mock user (locale-aware), initials helper, task list, logout stub.
useI18n — English / Japanese toggle. t(key, params) with placeholder interpolation. Locale persisted to localStorage.

Filtering Rules
Params set to 'all' are skipped (no filter applied)
Category matching is case-insensitive
Month filter accepts YYYY-MM or Q#-YYYY
Inventory endpoints do not support month filter (no time dimension)
Spending endpoints do not support any filter params
